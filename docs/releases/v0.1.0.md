First release.

Scooch moves the desktop wallpaper so icons do not cover the subject of the picture.

- macOS, Windows and Linux with GNOME, KDE Plasma, Xfce, Cinnamon or MATE.
- One background process, event driven, no timer.
- `scooch` turns it on, `scooch use` picks a picture, `scooch flip` allows mirroring, `scooch off` restores the wallpaper.

Install on macOS and Linux

```sh
curl -LsSf https://sohanbhat.me/scooch/install.sh | sh
```

Install on Windows

```powershell
irm https://sohanbhat.me/scooch/install.ps1 | iex
```

What was tested and what was not is in the README.
