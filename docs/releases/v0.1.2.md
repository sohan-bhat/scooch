Everything new since 0.1.1.

While Scooch is on, the Scooch icon sits in the menu bar on macOS, in the notification area on Windows and in the tray on Linux where the desktop has one, also after a login. The icon's menu opens the window, turns Scooch off and on, or quits Scooch, which puts the wallpaper back. Closing the window while Scooch is on leaves the icon there. On macOS Cmd+Q now turns Scooch off, where 0.1.1 only closed the window.

The slide on macOS and Windows

- In 0.1.1 the helper that draws the slide started at the move and often came up too late, so the picture swapped with no slide. The helper now starts with Scooch and stays parked, so a move finds the helper ready.
- A move in the first moments after Scooch starts, before the helper has parked, swaps plainly and as fast as with the slide off.
- On macOS the frames of a slide follow the display's refresh.
- On macOS the end of a slide can no longer show a black desktop.
- On macOS a change of Reduce motion takes effect at once.

Flip

- With Flip on, the picture changes side only for a clear gain, so an icon nudged to and fro no longer flips the picture to and fro.

Linux

- On GNOME an icon move no longer writes a desktop setting. Scooch keeps one picture file per screen and replaces that file, and GNOME Shell loads the picture again. A write of the background settings could freeze GNOME Shell 46, 23 times in 20,000 writes on GitHub's runners.
- A desktop that gives no answer within 10 s no longer holds Scooch up. Scooch tries again after 5 s, 30 s and then every 120 s.

Windows

- The uninstaller waits until every Scooch process has ended.

Downloads

- macOS on Apple silicon and Intel, `Scooch.dmg`
- Windows on x64 or Arm, `Scooch-Setup-x64.exe` or `Scooch-Setup-arm64.exe`
- Linux as a deb, `scooch_amd64.deb` or `scooch_arm64.deb`
- Linux as an rpm, `scooch.x86_64.rpm` or `scooch.aarch64.rpm`
- Linux as an AppImage, `Scooch-x86_64.AppImage` or `Scooch-aarch64.AppImage`

On macOS the app is not notarized, so the first open needs Open Anyway in System Settings under Privacy and Security.

On Windows the setup is not signed, so SmartScreen shows a warning the first time.

The command alone on macOS and Linux

```sh
curl -LsSf https://sohanbhat.me/scooch/install.sh | sh
```

The command alone on Windows

```powershell
irm https://sohanbhat.me/scooch/install.ps1 | iex
```
